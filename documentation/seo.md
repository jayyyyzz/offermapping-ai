# SEO 与社交预览

## 当前方案

应用是单页 React 站点，由 `index.html` 提供静态标题、中文语言标记、viewport、description 和 theme color。所有功能区在同一客户端页面中切换，没有服务端渲染、预渲染或动态元数据。

| 路由 | 需要索引 | 数据公开性 | 当前支持 |
|---|---:|---|---|
| `/` | 是 | 落地页与项目目录可公开 | 静态 title/description |
| `/api/*` | 否 | 部分公开、部分含用户数据 | 无 robots/header 策略 |
| 客户端功能区 | 否，当前不是独立 URL | 可能包含私人简历结果 | 无可抓取独立路由 |

## 安全边界

- 用户简历、分析结果和历史记录不得进入 HTML meta、结构化数据、站点地图或公开分享卡。
- 当前没有根据用户输入生成动态 meta，因此不存在元数据注入路径。
- Bot 与普通用户走相同静态 HTML，不存在 bot 专用数据接口。

## 上线前建议

- 修订并人工核对标题与 description，加入 canonical、Open Graph 和 Twitter Card。
- 增加 `robots.txt` 与 `sitemap.xml`，只收录公开落地页。
- 为生产域名和预览环境设置不同索引策略，预览环境应 `noindex`。
- 若未来增加可分享报告，默认必须私有且不可索引；公开分享需使用不可猜测令牌、撤销能力和显式用户确认。
