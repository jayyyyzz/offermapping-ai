# v0.2.0-demo

这是 OfferMapping AI 的本地 demo-ready MVP 里程碑。

## 本次包含

- 无模型密钥的本地规则演示链路。
- 服务端分析任务轮询，展示真实的 queued / running / saving / completed 状态。
- 登录、历史分析、账户及关联数据删除、隐私告知和第三方模型传输说明。
- 请求 ID、按接口限流、分析字符预算、模型输出 token 上限、事件/反馈/错误聚合表。
- 规则回退证据边界修复与新的 baseline smoke 报告。
- 前端 Playwright E2E 最小套件；CI workflow 保留在本地工作区，待 GitHub token 补充 `workflow` scope 后再推送。

## 已知限制

- 已发布公开 GitHub 仓库和 `v0.2.0-demo` Release；本次环境尚未绑定托管平台，因此还没有长期公开 Demo URL。
- Playwright runner 在当前桌面沙箱中会长时间挂起；本地 CI 配置已准备好，需在标准 CI runner 中执行并上传报告。
- 真实案例验证尚未完成；`documentation/real-case-validation.md` 只提供授权、脱敏和人工复核模板。
- 单实例内存限流与 SQLite 适用于 demo 和小规模探索，不等于生产级容量或合规承诺。
