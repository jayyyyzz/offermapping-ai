# 公开 Demo 部署说明

当前仓库已具备单容器部署形态，但本次没有可用的 Render、Railway、Fly.io 或云主机凭据，因此没有代替维护者创建公开 URL。

## 最短路径

1. 在托管平台选择 Docker 部署，并连接 `jayyyyzz/offermapping-ai`。
2. 使用仓库根目录的 `Dockerfile`，监听平台提供的 `PORT`（默认 8000）。
3. 设置 `TOKEN_SECRET`（至少 32 个随机字符）和 `ALLOWED_ORIGINS`；没有模型密钥时不要设置 `EXTRACTOR_*` / `GENERATOR_*`，应用会走本地规则链路。
4. 将持久化卷挂载到 `/app/data`，否则 SQLite 中的登录历史会随实例重启丢失。
5. 健康检查使用 `GET /api/health`。首次上线先用合成示例验证：填入示例 → 开始分析 → 等待任务完成 → 查看证据报告。

## 上线前检查

- 确认隐私告知已替换维护者联系方式，并明确第三方模型数据传输政策。
- 限制 `ALLOWED_ORIGINS` 为实际域名，不使用 `*`。
- 在平台侧设置请求/日志保留周期；删除账户接口只删除应用数据库中的数据。
- 观察 `X-Request-ID`、错误聚合和成本保护指标，确认超限请求返回可理解的错误。

## 当前限制

单实例内存限流和 SQLite 适合演示与小规模探索；多实例部署前应替换为共享限流存储、集中日志和托管数据库。
